# 🌐 Universal Telegram Tarjimon Bot (Aiogram 3)

## 🚀 Imkoniyatlar:
- **✍️ Matn tarjima**: O'zbek, Rus, Ingliz, Turk, Nemis, Arab, Xitoy, Koreys va boshqa tillar o'rtasida 2 tomonlama intellektual tarjima.
- **🖼 Rasm tarjima**: Rasmdagi yozuvlarni OCR orqali aniqlab tarjima qiladi.
- **📄 Hujjat tarjima**: PDF, DOCX, TXT hujjatlarni o'qib tarjima qiladi.

## 🛠 Kompyuterda ishga tushirish:
1. Terminal yoki CMD-da kutubxonalarni o'rnating:
   `pip install -r requirements.txt`
2. `.env.example` faylini `.env` deb o'zgartiring va tokeningizni yozing.
3. Botni ishga tushiring:
   `python bot.py`
